# Weather Forecast App

A responsive weather forecast application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Real-time weather data
- Temperature, humidity, wind speed
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeather API
